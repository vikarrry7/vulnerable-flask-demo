# Vulnerable Flask Demo

Учебный проект для практической работы по дисциплине "Разработка безопасного ПО".

## Описание
Демонстрационное Flask-приложение, содержащее типичные уязвимости:
- SQL-инъекции
- Небезопасная десериализация
- Command Injection
- Жёстко закодированные секреты
- Debug-режим в production

## Запуск
\`\`\`bash
pip install -r requirements.txt
python app.py
\`\`\`

⚠️ **Внимание:** Проект создан исключительно в учебных целях. Не используйте в production!
